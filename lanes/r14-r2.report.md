## What changed

- `crates/ec-av1/src/decode.rs:10891 rect_inter_residual_supported` — accepts `(64,32) (32,64) (64,16) (16,64)`.
- `crates/ec-av1/src/decode.rs:10903 rect_inter_luma_set` — `TxbSet::Luma64` for 64x32/32x64,
  `TxbSet::LumaRect32x16` for 64x16/16x64 (`av1_get_adjusted_tx_size`; both sets carry
  `tx_type: None`, correct because `tx_size_sqr_up == TX_64X64` makes the ext-tx set DCT_ONLY,
  so no `tx_type` symbol is coded and the intra/inter table split is moot).
- `crates/ec-av1/src/decode.rs:10921 rect_inter_chroma_set` — 32x16/16x32 → `ChromaRect32x16`,
  32x8/8x32 → `Chroma16` (same sets the INTRA superblock-strip path already uses).
- `crates/ec-av1/src/decode.rs rect_scan` — `SCAN_32X8` / `SCAN_8X32` arms.
- `crates/ec-av1/src/decode.rs read_inter_plane_rect` — the load-bearing change: a 64-length axis
  codes only its low 32 coefficients, so the unit read is the `min(w,32) x min(h,32)` corner,
  zero-extended into the true `w x h` grid before `dequant_and_inverse_typed_wh`. A square 32x32
  corner goes through the SQUARE reader with `rect_shape = Some((w, h))`, because
  `av1_nz_map_ctx_offset` is indexed by the real un-adjusted shape (class from lane-sbpart r8).
- `crates/ec-av1/src/decode.rs read_block_tx_size_rect` — NEW named refusal
  `"a split transform on a 1:4 inter strip with a 64-px axis"`: `sub_tx_size_map` is square for
  every shape this decoder splits (TX_32X16→TX_16X16, TX_64X32→TX_32X32) except TX_64X16→TX_32X16
  and TX_16X64→TX_16X32, where the existing square recursion would code the wrong tree.
- `crates/ec-av1/src/decode.rs` + `stream.rs:60` — `rect64_inter_tu_hits()` counter (luma 64-axis TUs).
- `crates/ec-av1/src/refusal_inventory.rs` — the new refusal registered.
- `crates/ec-av1/src/stream.rs` gate
  `a_real_aomenc_inter_sequence_with_a_superblock_level_rect_partition_decodes_pixel_exact`
  now hard-asserts `rect64_tus > 0` (the residual half of the arm; before, the gate proved only
  the partition symbol because every strip it accepted was `skip`).

Merge commit `399278b` resolved the single conflict (`cdf_state.rs` TxbSet match) by keeping BOTH
sides' arms (lane's 16x4 intra 1:4, main's 16x8 inter rect).

  `a split transform on a 1:4 inter strip with a 64-px axis`. This is the film's next blocker in
