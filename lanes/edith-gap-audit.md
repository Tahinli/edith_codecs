## Notes and conflicts with stale reports

- **`needs_plugin` text is still in code.** `demux.rs:144-161` has arms for HEVC, VP8, VP9 and AV1. The `Pulled::open` seats (`decode.rs:55-65`) return `Some` for HEVC, VP9 and VP8, so the HEVC/VP8/VP9 arms are unreachable. The AV1 arm is still reached from export (`export.rs:5236`). DONE.md's "the `needs_plugin` refusal is removed" is met in behaviour but not in the code.
- **`vp9sw` report says VP9 export stays refused.** That is superseded by `hevcexport`, which routes export through the software seats.
- **`vp8engine` report says VP8 export keeps its refusal.** Superseded for the same reason.
- **`swapinflate` report says miniz_oxide is in the engine's transitive tree via `image`.** The lock check here shows it is via the app's `image`, not the engine's normal tree.
- **Edith tests need local fixtures.** Most edith integration tests read `crates/engine/../../assets/` (gitignored, generated by `scripts/gen_fixtures.sh` with ffmpeg). Real-library tests use `real_library.toml` and return early when it is absent.
- **Silent passes.** `pgs_bitmaps.rs` (no real_library), `audio_truehd.rs` (skips without ffmpeg), and the `let-else` real-film tests all pass without running their assertions when media is missing. Counts in the lane reports should be read with that in mind.
