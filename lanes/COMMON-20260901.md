  merge into main, never `git checkout <file>` to revert (copy to scratch first).

  command. sccache is the global rustc wrapper. Use `nice -n 10 cargo ... -j3` — 10 lanes
  run concurrently on 12 cores / 30G RAM. Long/lavfi runs under
  `systemd-run --user --scope -p MemoryMax=8G` and bound ffmpeg with `-t`.
- Test scope: `cargo test -p ec-av1 --lib` only (plus `cargo check -p ec-av1`). Never the
  workspace suite. Set `EC_AV1_REQUIRE_AOMENC=1` so an absent oracle FAILS, never SKIPs.

  scripts/instrument-aom-oracle.sh; rungs EC_TRACE=1 / EC_TRACE_COEFF=1 / EC_TRACE_MODE=1 /
  EC_AV1_PREFILT_DUMP). Ours: EC_TRACE_COEFF / EC_TRACE_MODE / EC_TRACE_MODE_STEP in decode.rs.
  Cross-decoder bisection compares msac RANGE element by element, never tell().
  The reference is at the oracle source tree (find via scripts/build-aom-oracle.sh).
- FIRST STEP, always: `git log --oneline -8 main` and rebase your branch onto main
  (`git rebase main`; resolve conflicts, keeping main's fixes). Then RE-MEASURE your lane's
  premise before building — charters may carry stale premises. Cite the command that
  produced every premise you act on.
- Fixtures: `fixtures` is a symlink to main's fixtures dir (shared). Pin any new stream
  fixture under crates/ec-av1/fixtures/ or fixtures/ with a hash; hash an aomenc output
  TWICE before trusting a seed (lavfi gradients ignores its seed).
- A refusal is lifted ONLY together with a gate: a real-aomenc stream (tool explicitly
  enabled on the aomenc command line) decoded pixel-exact vs ffmpeg/aomdec, that
  HARD-ASSERTS a hit counter proving the feature fired, and never turns a decode error or
  pixel mismatch into SKIP. Update refusal_inventory.rs + gate_coverage.rs in the same
  commit. `refusal_inventory` and `gate_coverage` tests must stay green.
- Defect classes to check first (memory-proven, each cost rounds): CDF row indexed by a
  field that moves; table indexed by RAW vs adjusted tx_size; scan/ctx tables transposed
  vs spec (libaom layout is not the spec's — gate on asymmetric behaviour); neighbour ctx

  never consumed; counter-reset list missing a table; call-site arg order; a probe loop

  `lanes/<lane>-r<N>.handoff.md` with exact facts (ranges, stream, element) so a fresh
  agent continues without re-reading.

  what changed (path:line), gate name + command + result, refusals lifted, test totals
  (`cargo test -p ec-av1 --lib` passed/failed/ignored), and EVIDENCE lines of the form

## AOMENC FLAG PRECEDENCE (measured 2026-09-02 08:45, md5 of 4 orderings)
aomenc keeps the LAST occurrence of a repeated `--enable-*` flag. Per-arm overrides go AFTER the
base recipe. Every gate proves its flag arrived through a decoder-side counter or a header field;
a counter at 0 means the flag did not arrive or the encoder declined — never weaken the assert.
