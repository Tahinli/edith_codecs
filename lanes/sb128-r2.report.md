## What changed

- `crates/ec-av1/src/decode.rs`
  - `read_sb128_root()` (~11250): the 128 root extracted out of the key-frame loop — one
    `read_lr` over the whole 128x128, one `partition_w128` symbol (8 symbols, `gather_of` +
    `VERT_ALIKE128`/`HORZ_ALIKE128` at the frame edge), refusal by name for the seven
    non-SPLIT arms. Both tile loops call it, so they cannot drift apart.
  - `decode_inter_frame_tile_with_cdfs` (~18380, ~18570): `let sb128 = sb128();` and the
    superblock loop replaced by `sb_visit_order(...)` + the 128 prologue. `delta_q`/`delta_lf`
    already key off `sb_mi_cur()`; `CDEF_TRANSMITTED` is reset per 64x64 quadrant, which is
    exactly libaom `read_cdef`'s per-quadrant `cdef_transmitted[index]`, index
    `(mi_col&16)>>4 + 2*((mi_row&16)>>4)`.
  - warp-sample `has_top_right` (13470) hardcoded `SB_MI` (a 64x64 superblock); now delegates
    to the single sb-aware port.
- `crates/ec-av1/src/mvstack.rs`: `has_top_right()` ported from libaom `mvref_common.c:264`
  (`sb_mi_size = mi_size_wide[seq.sb_size]`, so the mask loop runs one level further at 128);
  both `scan_top_right` and `scan_top_right_compound` are now gated on it instead of a bare
  "is the grid cell populated" probe. corner-cut in the doc: the three rect/`VERT_A` shape
  refinements are not ported (ceiling = rect/AB INTER leaves, refused by name today).
- `crates/ec-av1/src/stream.rs`: the r1 refusal test replaced by the r2 gate (below), plus the
  `sb128_r2_control_sb64` control; the inter refusal restored with the residual named.

MEASURED, against the charter's premise: libaom `check_sb_border` (mvref_common.c:318) uses
`mi_size_wide[BLOCK_64X64]`, **hardcoded**, NOT `seq_params.sb_size` — the charter said to port
it as sb-derived. `mvstack.rs`'s `sb_mask = 16` is therefore already correct at 128 and was
left alone. `has_top_right` (line 266) is the one that is sb-derived.
