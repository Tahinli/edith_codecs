# lane-fi8 r1 -- filter intra on a sub-8 4x8/8x4 rect leaf

Branch `lane-fi8` off main 8262b99, commit 2d5c425.

## Root cause (two defects, one block shape)

1. **Wrong CDF row, not a missing symbol.** `read_intra_mode_sub8`
   (`crates/ec-av1/src/decode.rs`) is shared by `decode_leaf_split4`'s
   BLOCK_4X4 leaves and `decode_leaf_rect8`'s 4x8/8x4 leaves, and read
   `use_filter_intra` from `cdfs.filter_intra[0]` -- BLOCK_4X4's row --
   unconditionally. `av1_filter_intra_allowed_bsize` (both sides <= 32) allows
   BLOCK_4X8/BLOCK_8X4, and libaom reads them with
   `default_filter_intra_cdfs[BLOCK_4X8]`=6743 / `[BLOCK_8X4]`=5893, so the
   symbol was READ (no `symbol-consumption-gap`) but out of the wrong interval:
   the same value, a divergent range, a desync a block or two later (class
   `wrong-alphabet-same-value` / `cdf-row-held-constant`). Fixed by adding
   `cdf::FILTER_INTRA` rows 8/9 (values generated by
   `scripts/extract-filter-intra-cdfs.py`), mapping them in
   `filter_intra_size_class_rect`, and passing the leaf's own class in.
2. **Stale refusal.** `"filter intra on a HORZ/VERT strip (this decoder
   predicts square-only)"` -- `predict_filter_intra` has taken a true `bw`x`bh`
   since lane-rectsplit. `filter_intra` is now threaded into both whole-leaf
   `reconstruct_rect` calls and, under `tx_depth=1`, into each 4x4 transform
   unit's own `reconstruct` / `read_plane` (per-TU prediction off the previous
   unit's reconstruction). Refusal removed from `refusal_inventory::REFUSALS`.

## Same-class sweep (tx_type row under filter intra, the 1a89ed9 defect)

`grep "cdfs.txb("`: the coded 16x8/8x16 (`decode_leaf_rect`) and 32x16/16x32
strips still passed the block's raw `mode` (always DC_PRED under filter intra)
as the `intra_ext_tx_cdf` row. All three rect sites plus the new sub-8 one now
go through `fi_tx_row` (`fimode_to_intradir`), which `read_plane` shares
instead of its private const. 64x32/32x64/32x8 sites are past
`av1_filter_intra_allowed_bsize` and were left alone.

## Gate

`a_real_aomenc_stream_with_filter_intra_on_a_sub8_rect_leaf_decodes_pixel_exact`
(`crates/ec-av1/src/stream.rs`): the `sub8_rect_leaf` recipe with
`--enable-filter-intra=1` and `--enable-tx-size-search=1|0` as the FIRST
occurrence of each flag (aomenc keeps the first). Three arms (8-bit txs=1,
8-bit txs=0, 10-bit txs=1), 80 attempts each, and an attempt only counts when
the per-attempt `filter_intra_rect_sub8_hits` delta is nonzero AND all three
planes match ffmpeg. No SKIP path except the tool-absence one
(`EC_AV1_REQUIRE_AOMENC=1` was set for every run below).
