- `decode_leaf_split4`: `has_chroma` now branches per subsampling — 4:4:4
  every leaf, 4:2:2 `(lmi.1 & 1) == 0` (every even-mi-column leaf), 4:2:0
  `i == 3` unchanged. A `chroma_422` flag (ss_x 1, ss_y 0) and a
  `last_uv422` coarse-slot value were added; the group tail gained a 4:2:2
  branch that only fills `above_uv_mode`/`left_uv_mode` from the group's
  last chroma-reference leaf (bottom-left), and the tail's chroma state
  stamp is skipped at 4:2:2 (the per-leaf units already stamped).
- New `sub8_leaf_chroma422` (beside `sub8_leaf_chroma444`): one square
  TX_4X4 chroma unit per plane at the chroma position
  (`px >> ss_x`, `py >> ss_y`) — `ss_size_lookup[BLOCK_4X4][1][0]` is
  BLOCK_4X4, so the (2,4) plane area rounds up to the square 4x4 read — via
  `read_plane`'s proven `TxbSet::Chroma4` + `TX4` route, with
  `Neighbours::around_mi_422_chroma(lmi, 8, 4)` context reads (the unit's 4
  chroma-px width spans TWO luma mi columns; sampling every second above

  (1 mi row tall, both luma mi columns of the one chroma column).
- New `CHROMA422_SUB8_HITS` witness counter, bumped only on the two
  coefficient-reading arms (skip does not count); printed as
  `chroma422_sub8` by `examples/decode_probe.rs`.
- Untouched: `decode_leaf8`, `decode_rect4_16_strip`, `decode_block_128rect`,
  `decode_rect_split`, the 4:2:0 group tail (including its SKIP arm at
  decode.rs:19169-19170 — the sibling-owned flat-DC miss), the square-block
