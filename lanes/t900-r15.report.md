The two "NOT in start_tile" rows are safe, not fixed: an `above[c]` cell is only
ever written by a block in the SAME tile column, so a stale value is reachable
only at the tile's first mi row, which the `mi_r > tile_row0_mi` guard blocks —
and `uv_mode_grid_override_hits()` (asserted 0 by the uv_mode gate, and 0 in
this round's decode of the pinned stream) is the standing counter for exactly
that read. Disposition: accepted.
