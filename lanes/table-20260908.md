# Standing quality table of main 152996c8 (measured 2026-09-08, lane-table)

One re-measurement of every native BD row on ONE base, so the lanes merged today
(ARF temporal filter, 128x128 superblocks by default, per-level delta_q, motion
search rate weight, pricer contexts) are read off the same binary instead of five
different lane bases. MEASUREMENT ONLY -- no encoder change is in this lane.

Binary: `cargo test -p ec-av1 --release --lib` at 152996c8, one tile, one thread.
Anchors: libaom `cpu-used 6` (crf 5/20/35/45), rav1e `speed=6` (quantizer
50/100/150/200). Every BD number below is read off the log's own table line.
`fps` = coded frames / our ladder wall (48 = 4 points x 12 frames on the 12-frame
arm, 192 = 4 x 48 on the long-GOP arm), single thread.
