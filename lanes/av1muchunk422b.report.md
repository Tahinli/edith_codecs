## What the prior lane missed

The prior lane's eight recipes all read `part128 none=0`: a 384x256 frame leaves
aomenc free to split every 128 superblock, so the `side > 64` walks never ran
even though a 128x128 superblock was available. The streams that DO reach these
walks are 128-as-the-whole-frame — `--sb-size=128 --min-partition-size=128
--max-partition-size=128` (PARTITION_NONE forced) — and **LOSSY**. The lossless
branch of each arm returns before the unit loop, which is why
`W_intrabc.obu` reaches both guards at ss (1,0) and allocates nothing. That
zero is real, and it is why the new counters count at the **allocation**, not at
the guard.

## Why the compound gate is not an exactness witness

**7 of the 8 streams this lane generated DIVERGE from ffmpeg; only
`i6_grad128_iis` is byte-exact.** The compound fixture (`i8_tsrc128_iis`) is one
of the seven. On this tip the divergence is Y and U exact, V differing on a
fixed column band (2063/8192, 2138/8192, 2105/8192, 1988/8192 V samples on
shown frames 1-4, first at V row 60 col 36) — the same shape on all four
compound streams, while the committed 4:2:2 128-root SINGLE-reference stream
(`422_sb128_3f.obu`) and the committed compound-warp stream whose blocks are all
<= 64 (`422_residual_compound_warp_16f.obu`) both stay exact. So the divergence
tracks the 128-root COMPOUND path — which is exactly what these counters name.

It is a **NEW defect** and out of this lane's charter (the charter was the
witness). The test says so in its comment; when a fix lane lands, add the oracle
compare to the compound test. The counter half is already in place so the
fixture cannot silently stop reaching the walk it was pinned for.

## Non-vacuity

- **Shape assert first.** Each gate asserts the fixture parses as
  `use_128x128_superblock=true, ss=(1,0), non-mono`; a stream that came back
  4:2:0 would leave the walk unexercised while every counter assert still passed.
- **Cross-cell separation.** Each gate asserts the *other* arm's counter at
  ZERO, so neither can pass by running its sibling's walk. `is_compound` routes
  the single-reference twin (site 5) out of the compound counter.
- **Fixture pin.** Length + FNV-1a64 asserted; a missing/moved fixture is a
  failure, not a skip.
- **Red-proof (intra gate).** Forcing the site-8 bump to never fire
  (`if false { hit!(MU_CHUNK_INTRA_IN_INTER_UNITS); }`) reddens gate 2 at
  `stream.rs:43027`:

  ```

  -- the site counter this gate names did not move
  ```

  Reverted; re-run green.
- **Counter-proof (in gate 2).** `W_intrabc.obu` is decoded and asserted to
  allocate `(0, 0)` mu-chunk units while `INTRA_128_IN_INTER_MU_CHROMA_HITS`
  fires 8 times — pinning the guard-to-allocation gap the design rests on.
