# Standing quality table of main 0dc2f731 (measured 2026-09-09, lane-table2)

One re-measurement of every native BD row on ONE base, so the six lanes merged
since the 2026-09-08 table (`b128r` compound 128 root, `arftf` ARF filter
strength 2, `rlclamp` rate loop, `edge128` CDEF owner map, `b128hv` HORZ/VERT
128 root, `lookahead` one mini-GOP of lookahead + ±3 ARF window) are read off
ONE binary instead of six different lane bases. MEASUREMENT ONLY -- no encoder
change is in this lane.

Binary: `cargo test -p ec-av1 --release --lib` at 0dc2f731, one tile, one
thread. Anchors: libaom `cpu-used 6` (crf 5/20/35/45), rav1e `speed=6`
(quantizer 50/100/150/200). **Sign convention: BD-rate, LOWER IS BETTER** (a
negative number means we spend fewer bits than the anchor at equal quality);
every BD number below is read off the log's own table line. `fps` = coded
frames / our ladder wall (48 = 4 points x 12 frames on the 12-frame arm,
192 = 4 x 48 on the long-GOP arm), single thread.

Every gate ran alone, in `systemd-run --user -p MemoryMax=14G`, after a wait
for 1-minute load < 4; each log carries its own `LOADAVG_BEFORE` /
`LOADAVG_AFTER` line and ends `RC=0`. Logs: `~/.cache/table2/*.log`.

Deviations from this lane's charter, named:
- The charter's gate command omits `--ignored`; both BD tests carry
  `#[ignore]`, so `--ignored --exact` was used (without it the test filters out
  and the gate reads "0 passed" -- a silent no-measurement).
- One `systemd-run` unit (`table2-driver`) runs the twelve gates SERIALLY, each
  after its own load wait and each into its own `~/.cache/table2/<n>.log`
  ending `RC=`, instead of twelve separate units. Same isolation, same
  MemoryMax=14G, same one-gate-at-a-time property; it removes the operator poll
  between gates. The driver script is `~/.cache/table2/driver.sh`.
