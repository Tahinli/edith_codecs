# lane-b64b — the 64x64 root: compound, var-tx, edge, intra

Branch `lane-b64b`, base `12a8c4a7`. Scope: `crates/ec-av1/src/encode.rs`'s 64
root (`search_skip_64`, its residual arm, `sb64_legal`), `tile.rs`'s
`Quadrant::Whole64` writer arm, tests.

## Step 1 — COMPOUND references at the 64 root (commit `b9a4d589`)

Search: `search_skip_64` takes this superblock's `LAST` + GOLDEN/ALTREF
compound stacks (`find_mv_stack_compound` at the 16x16-mi window the writer
rebuilds from) and prices three modes — `NEAREST_NEARESTMV`,
`GLOBAL_GLOBALMV`, `NEW_NEARESTMV` — through `predict_compound_u8`, a heap
counterpart of `predict_u8` on the same `predict_compound_intermediate` +
`combine_compound` path (`mc_trial_compound`'s fixed buffers are sized for a
32x32 block, so they cannot serve a 64 root). Every candidate is compared
against the single-reference arm at ONE syntax price: `fixed` minus the single
reference tree, plus the pair tree and the compound mode symbol.

DEVIATION from the charter, named: `NEAREST_NEWMV` and `NEW_NEWMV` are NOT
offered. Both need the SECOND reference's own `NEWMV` vector, which only a
second 64x64 motion search per superblock produces — the wall this root exists
to save (`b64_residual`'s doc: a root that wins is four quadrant searches that
never run). The three modes above cost no extra search.

Writer: the `Whole64` arm's "a 64x64 root block is coded single-reference"
refusal is gone; a compound root codes `comp_mode` 1 and the whole
`write_compound_block` chain at `(bw4, bh4) = (16, 16)`, publishes both
references and both vectors into the MI grid, writes NO `motion_mode` symbol
(libaom's `motion_mode_allowed` refuses a compound block) and stamps
`record_block_compound` so the next block reads the right compound contexts.

`EC_AV1_B64COMP=0` restores the single-reference root, so both arms measure on
one build.

### Exactness

`encoder::tests::a_crossfade_clip_codes_a_compound_64x64_root_and_decodes_sample_exact`
— a 9-picture linear crossfade between two test cards, so on a leaf frame the
average of `LAST` and `ALTREF` IS the source: 2 compound 64x64 roots fire and
every frame decodes sample-exact through our decoder AND ffmpeg, with
`EC_COMP_MISMATCH=1` printing nothing.
