# lane-fi32x8 r1 — 32x8/8x32 strips read `use_filter_intra`

## Defect (class symbol-consumption-gap), confirmed on main 11633d7

`decode_block_rect4` (decode.rs:5817) decodes the 32x32-level `PARTITION_HORZ_4`/
`PARTITION_VERT_4` arms — four 32x8 (or 8x32) strips — and hands `(bw, bh)` to
`read_intra_mode_rect`, but `filter_intra_size_class_rect` returned `None` for both
shapes, so the `use_filter_intra` symbol libaom writes for every DC_PRED block inside
`av1_filter_intra_allowed_bsize` ("both sides <= 32") was never read there. Since
`--enable-filter-intra` is ON by aomenc default, any such stream desynced the tile
silently from that strip on. Every gate that reached these strips spelled
`--enable-filter-intra=0`, so nothing could see it ([[tool-disabled-in-every-gate]]).

- `crates/ec-av1/src/cdf.rs:466` — `FILTER_INTRA` grows to 10 rows: `[8] = 18101`
  (BLOCK_32X8, BLOCK_SIZES_ALL index 19), `[9] = 20229` (BLOCK_8X32, index 18). Values
  come from `scripts/extract-filter-intra-cdfs.py` against `~/.cache/aom-oracle/src`,

- `crates/ec-av1/src/cdf_state.rs:544` — the `Cdfs::filter_intra` field's array size.
- `crates/ec-av1/src/decode.rs:4292` — `filter_intra_size_class_rect` maps `(32, 8) =>
  8`, `(8, 32) => 9`.
- `crates/ec-av1/src/decode.rs:950` — new orientation-split counters
  `FILTER_INTRA_RECT4_HORZ_HITS` / `..._VERT_HITS` (rows 8/9 are asymmetric, so a
  one-sided gate would pass on a transposed pair), incremented in `decode_block_rect4`.
- `crates/ec-av1/src/decode.rs` domain test
  `filter_intra_classes_carry_their_own_libaom_default_row` — `(8, 32)`/`(32, 8)` move
  from "refused before any leaf (PART32)" to owning a class; the stale `PART32` refusal
  string is gone. The 16-level pair (4x16/16x4) is still listed as refused.
- `crates/ec-av1/src/stream.rs:16940` — the gate (below).

No refusal string was lifted this round, so `refusal_inventory.rs` is untouched: the
32-level 1:4 partition was already decoded, only its filter-intra symbol was missing.
Prediction needed no new code — `predict_filter_intra` is already generic in `(bw, bh)`
(lane-rectsplit r1) and `reconstruct_rect` already routes `filter_intra` into it. No
`fi_tx_row` remap is needed at this shape either: `TxbSet::LumaRect32x8` carries
`tx_type: None` (tx_size_sqr_up is TX_32X32, ext-tx set 0), so no `tx_type` symbol is
read on a 32x8/8x32 luma block at all.

### Fixture tuning (measured, not guessed)

The sibling gate's noise level (6..15) is too low: with it, filter intra was picked on a
1:4 strip in 3 of 40 8-bit attempts and in **0 of 40** 10-bit ones (`EC_FI32X8_VERBOSE=1`
per-attempt lines). Raising the noise layer to 18..27 makes the flag fire in most
attempts at both depths — filter intra is what aomenc's RD reaches for on a noisy flat
band. A gradient-ramp variant and `--cq-level=63` were both tried and dropped: cq 63
mismatches on this fixture *with filter intra disabled* (see residue).

`EC_FI32X8_GATE_ATTEMPTS` (default 16 — attempt 13 is the first 8-bit VERT_4 firing) and
`EC_FI32X8_VERBOSE` are the only knobs kept.
